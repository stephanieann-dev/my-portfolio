# Stephanie Ann — Professional Portfolio

Personal portfolio website showcasing Stephanie Ann's experience, technical skills, projects, certifications, and resume.

## Overview

This portfolio is designed for remote and entry-level opportunities in:

- AI Data Annotation
- Data Entry
- Virtual Assistance
- IT Support
- Technical Support

## Features

- Responsive design for desktop, tablet, and mobile
- Interactive navigation and subtle animations
- Project and credentials sections
- Downloadable resume
- Contact form for direct inquiries
- Accessible, clean, professional layout

## Built With

- HTML5
- CSS3
- JavaScript
- Responsive web design
